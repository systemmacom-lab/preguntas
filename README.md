# Preguntas para Macom

Las páginas de los envíos de preguntas a Macom, publicadas con GitHub Pages en
https://systemmacom-lab.github.io/preguntas/.

- **Cada envío vive en su carpeta** (`e-01/`, `e-02/`…) y su dirección no cambia.
- **La página de un envío no se edita después de mandarla**: lo que siga abierto, más lo nuevo, va en
  el envío siguiente, en una carpeta nueva, y se agrega a la lista de `index.html`.
- **Las respuestas llegan por correo.** Cada página tiene enlaces que abren el programa de correo con
  la dirección, el asunto y la pregunta ya escritos. Para quien use el correo desde el navegador,
  donde el enlace puede no abrir nada, muestra la dirección y el asunto, con botones para copiar la
  dirección y cada pregunta.

El registro de las preguntas, con sus respuestas y lo que se decidió con ellas, vive en
`documentation/preguntas/` del repositorio de la solución Macom; este repositorio solo publica las
páginas.
